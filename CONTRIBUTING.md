# Contributing

Thank you for improving Correlation-Based Range Detection.

## Development workflow

1. Create a branch from `main`.
2. Keep public functions documented with MATLAB help text.
3. Add or update tests for behavior changes.
4. Run `runtests("tests")` in MATLAB R2021a or newer.
5. Open a focused pull request describing the motivation and validation results.

Please avoid committing generated MATLAB caches, test reports, or editor settings.
